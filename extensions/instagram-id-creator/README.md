# MediaHub Instagram ID Creator

1. In the Chrome profile that opens MediaHub, visit `chrome://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this exact folder.
4. After a code update, click the extension's reload icon, then refresh `https://localhost:3443/insta-id-creator`.

The extension only receives a form-fill request after the **Open and fill Instagram** button is clicked. It opens Instagram, fills the visible account-sign-up fields, and stops. It does not persist credentials, click Submit, solve challenges, or read verification codes.
